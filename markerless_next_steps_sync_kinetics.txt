TOOLS / METHODS DECISION
- Python + ezc3d + NumPy/SciPy: first choice for force-plate QC, CoP/GRF extraction, COM tests, and simple transparent baselines.
- OpenSim: strongest practical first reference for established musculoskeletal inverse dynamics if the model and external loads can be set up correctly.
- Nimble Physics: compelling later alternative for human skeleton inverse dynamics, multiple contacts and differentiable optimization; requires model-coordinate fitting, compatible skeleton, external load conventions and testing; beta API.
- AddBiomechanics: Nimble-powered automated mocap workflow, but uploaded data become public; DO NOT upload participant data without appropriate permission and ethics/data-governance clearance. Do not use force-optimized motion for independent force-prediction validation.
- In ALL cases, scientifically valid inverse dynamics depends on accurate kinematics, segment inertial parameters, reference frames, external forces/CoP, and synchronization. Solver choice does not correct unreliable input data.
